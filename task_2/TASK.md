# Вариант 2: устройство для считывания штрихкодов на конвейере

## Задача

Придумать программно-аппаратный комплекс, который решает задачу считывания штрихкодов, наклеенных на картонные коробки.

## Вводные

- Ширина конвейера — **650 мм**.
- Скорость движения коробок — **1 м/с**.
- Интервал между коробками — **2 секунды**.
- Размер коробок — **600 × 400 × 400 мм**.

На коробках наклеены штрихкоды. Штрихкоды могут быть произвольно наклеены на любую грань коробки.

Пример штрихкода:

> *Изображение штрихкода не приложено.*

Размер штрихкода:

> *Размер не указан.*

На одной коробке может быть наклеено несколько штрихкодов, в том числе несколько штрихкодов на одной грани.

Для каждой проезжающей коробки нужно считать все штрихкоды и передать их в систему управления конвейером, которая примет решение о сортировке коробки на основе считанных штрихкодов.

Устройство можно разместить не дальше **трёх метров** от секции конвейера, которая сортирует коробки.

## Ожидаемый результат

В отчёте необходимо:

- выбрать набор сенсоров и указать их характеристики;
- предложить конкретные модели сенсоров и обосновать их выбор;
- определить физическое расположение выбранных сенсоров;
- подобрать вычислитель и обосновать выбор локальной и/или облачной обработки данных;
- описать алгоритм считывания штрихкодов — от момента сбора данных с сенсоров до отправки результатов считывания;
- при наличии нейросетей в предложенном алгоритме обосновать выбор конкретной архитектуры и описать характеристики датасета, необходимого для обучения:
  - количество изображений;
  - способ разметки;
  - количество классов;
  - способы аугментации и прочее;
- в случае использования готовых библиотек и/или фреймворков обосновать их выбор;
- определить ключевые метрики оценки качества предложенного решения;
- описать возможность масштабирования устройства для разных форм-факторов коробок и типов штрихкодов.

Опционально можно реализовать базовую версию предложенного алгоритма.

## Формат результата

- отчёт в формате `.pdf`;
- опционально — демо работы алгоритма и исходный код в виде проекта на GitHub с `README.md` и инструкциями по запуску.
